Travel Pro: AI Travel Planner
Travel Pro is an AI-powered travel planning application that uses multiple AI agents to create personalized travel itineraries based on the user's destination, dates, budget, and interests.

Features
Personalized travel itinerary generation
Transport and hotel recommendations
Weather information
Budget calculation and validation
RAG-based travel information retrieval
Interactive maps and route visualization
User authentication and trip management
Technologies Used
React and Vite
Python and FastAPI
LangGraph and LangChain
Generative AI and RAG
MongoDB
Open-Meteo Weather API
